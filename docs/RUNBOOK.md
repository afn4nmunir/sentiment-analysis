# RUNBOOK

## 1. System Requirements
- Node.js up to date
- npm up to date
- AWS CLI configured
- Git installed

## 2. Setup instructions
- git clone <https://github.com/afn4nmunir/sentiment-analysis>
- cd sentiment-analysis
- npm install

## 3. Running Frontend
- npm run dev

## 4. Running Tests
- npm test

## 5. Running Lint
- npm run lint
